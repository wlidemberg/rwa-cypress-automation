# RWA Cypress Automation

Projeto de estudos de Qualidade de Software e Automação de Testes utilizando Cypress com base no Real World App (RWA) da equipe Cypress.

## Objetivos

* Aprimorar conhecimentos em Quality Assurance (QA)
* Desenvolver testes automatizados utilizando Cypress
* Aplicar boas práticas de Git e Git Flow
* Utilizar GitHub para versionamento e revisão de código
* Documentar funcionalidades utilizando artefatos de QA
* Criar cenários de teste baseados em regras de negócio
* Executar testes manuais antes da automação
* Evoluir para integração contínua com GitHub Actions

## Estrutura do Projeto

